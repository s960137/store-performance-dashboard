# 專櫃業績晨會表

將樓管後台下載的 Excel 報表拖進網頁，即可整理各專櫃的當日、去年當日、月累與年累業績，快速查看業績差異、專櫃排行與當天沒有業績的專櫃。

## 直接使用

**[開啟專櫃業績晨會表](https://s960137.github.io/store-performance-dashboard/)**

不需要下載或安裝程式。開啟網站後，將樓管後台下載的 Excel 拖進頁面即可。

## 使用方式

1. 開啟網站，按「匯入 Excel」將檔案拖進頁面。
2. 檢查系統自動辨識的欄位；如有不同，使用下拉選單重新指定。
3. 確認報表日期後匯入。
4. 在早會使用 KPI、專櫃排行與完整明細；也可按「複製早會摘要」或「列印」。

支援 `.xlsx`、`.xls`、`.csv`。必要欄位為專櫃名稱、當日業績、去年當日、月累業績與年累業績；月累與年累各需提供「去年同期」或「差異」其中一欄，系統便能補算另一欄及成長率。

## 資料安全

- Excel 內容只在使用者目前的瀏覽器中解析，不會傳到伺服器。
- 重新整理頁面後，已匯入資料就會清除。
- 儲存庫不包含任何真實業績檔；`.gitignore` 也會排除 Excel 與 CSV。
- GitHub Pages 網站本身可以公開，但每位同事匯入的業績仍只存在自己的電腦。

## 本機執行

需要 Node.js 20 以上版本。

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
```

## GitHub Pages

推送到 `main` 後，`.github/workflows/deploy.yml` 會自動建置並發布。第一次使用時，請到儲存庫的 **Settings → Pages → Build and deployment**，確認 Source 為 **GitHub Actions**。

## Excel 欄位相容性

系統會從第一個工作表的前 30 列尋找，並辨識常見中文名稱，例如：

- 專櫃名稱、中文名稱、品牌名稱
- 本日／當日／今日業績、去年當日
- 月累業績、去年月累、月累差異、月累成長率
- 年累業績、去年年累、年累差異、年累成長率

若後台欄名或欄位順序改變，匯入確認畫面可手動重新對應，不需修改程式。

## 技術

React、TypeScript、Vite、SheetJS、Recharts。所有報表處理均在前端完成。
